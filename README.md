# 💼 Portfólio / Currículo Web - Júlio César Saboya

Este projeto é um currículo online desenvolvido com HTML e CSS, criado para apresentar minhas informações profissionais de forma organizada e acessível.

A página contém informações de contato, objetivo profissional, formação acadêmica e habilidades.
